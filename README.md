# وصّل — Landing page (React + Vite)

```bash
npm install
npm run dev      # local development
npm run build    # production build in dist/
```

Deploy on Vercel: import the repo, framework preset **Vite** (build `npm run build`, output `dist`).

- Styles: `src/styles.css` (all colors are CSS variables at the top).
- Content and behavior: `src/App.jsx`.
- Images and logo: `public/assets/`.
